# Sum1reM0d

Sumire Labs の不条理なルールをMinecraftへ追加するMod

![Sum1reM0d](src/main/resources/assets/sum1rem0d/icon.png)

## 石鹸

石鹸は粘土玉・砂糖・水入りバケツを各1個、順不同でクラフトすると4個作れます。空バケツは返却されます。
手に持って使うと清潔度が初期値で50回復します。清潔度が満タンなら消費しません。
材料・作成数・回復量はConfigの「清潔度」で変更でき、機能OFF時は使用効果も停止します。
クリエイティブの「道具と実用品」・検索、または `/give @s sum1rem0d:soap` でも入手できます。
専用テクスチャとModアイコンは画像生成ツールで制作しました。[制作記録](art/README.md)

## ビルドとリリース

push・プルリクエスト時にGitHub Actionsで全対応対象をビルド・テストします。
テスト用JARはActionsのBuild実行ページにあるArtifactsから取得できます。

Gitタグをpushすると、全対象のビルド成功後にGitHub Releaseを自動作成し、
Minecraft版・ローダーごとのJARを添付します。リリースノートも自動生成します。
例えば `git tag 1.0.1` → `git push origin 1.0.1` で公開します。
利用者は自分のMinecraft版・ローダーに合うJARを1個選んで導入してください。
Forgixによる統合は現在無効です。

## 鉱石ドロップ交換

Config画面の「鉱石ドロップ交換 → 交換モード」をクリックして切り替えます。
固定、ワールド固定ランダム、日替わりランダム（初期値）、採掘ごとのランダムに対応します。
変更は一覧の「適用」後、次のドロップから反映します。
日替わりは全次元・全プレイヤー共通で、同じ日の対応表は再起動後も維持されます。
交換表の右側がランダム出力の候補です。幸運・シルクタッチ・深層岩への適用は個別に設定できます。

## 朝の異変抽選

毎朝、最大1種類の異変を抽選し、その日だけ発動します。対象はヴィーガン化、燃費変動、草の上下反転、
鉱石のダイヤ偽装、石・深層岩の硬さ交換、精錬装置の見た目交換、インベントリ交換、木・作物の成長停止、ナイリウム横倒し、旧ネザーラックです。
アーダイト／マニュリン化は抽選の対象外となり、ConfigがONなら常時適用します。
月齢による発動条件は使いません。鉱石ドロップの4モード・睡眠不足は独立です。

「朝の異変抽選」の発生確率は初期値80％。各機能の「朝の抽選で選ばれる重み」は初期値20です。
10機能すべて有効なら各8％・異変なし20％になります。重み0または無効の機能は選ばれません。
確率・重みの変更は翌朝から反映し、同じ日や再起動時の再抽選は行いません。ON/OFFは次の処理から反映します。
インベントリ交換は、選ばれた日に交換可能なプレイヤーの組が揃った最初の処理で1回だけ行います。

## 矢細工台のGUI

Minecraft標準のコンテナ枠、スロット、作業台の矢印、ボタンを組み合わせて表示します。
外部GUIライブラリの追加は不要です。材料、作成ボタン、完成品27枠、プレイヤー所持品の順に配置します。
1回1000本の出力やスタック上限、Shiftクリック、閉じたときのアイテム返却は従来どおりです。

## ゲーム内Wiki

ゲーム参加後、読み込みと設定の同期が終わると専用Wikiを開きます。
導入、12カテゴリ、全84機能の説明、検索、現在の設定値を収録しています。
左のカテゴリと「カテゴリ一覧」から記事を選び、右のページボタンやマウスホイールで読み進められます。
検索は機能名・ID・説明文が対象です。閉じても同じ接続中に勝手に開き直しません。

タイトル・ポーズ画面の「Sum1reM0d Wiki」、Config画面の「Wiki」からも開けます。
個人設定の「ゲーム内Wiki」で、自動表示OFF、初回だけ表示、待ち時間、既読状態を変更できます。
初期設定は参加するたびに1秒後の表示です。読み込み中や他画面の表示中は待機します。
初回の自動表示時に既読を保存し、初回判定は同じクライアント設定内で共通です。

Wikiはオフラインの標準GUIで、MCEFや外部サイトへの接続は不要です。
シングルプレイでは通常のメニュー同様に一時停止し、マルチプレイの世界は進み続けます。
閲覧にOP権限は不要です。サーバー設定の変更権限は既存のConfig画面で管理します。

## ブラウザと広告

ブラウザはインベントリ本体を動かさず左側に表示し、閉じると表示だけ隠して同じセッションで再生を続けます。
既存Configでは個人設定の「MCEF YouTube → 画面を閉じたら停止」をOFFにしてください。
表示幅・高さ・左側の間隔を個別に調整できます。空き幅が不足する場合は縮小し、極端に狭い場合は表示を隠します。
レシピブックの領域も避けます。JEIにはブラウザ領域を除外領域として通知します。

広告枠はエンチャント台・金床で個別にON/OFFできます。「広告ページURL一覧」に通常のWebページURLを指定します。
新規設定の開始URLはYouTubeです。既存の架空広告URLは設定で変更でき、組み込み広告も選べます。
サイトが配信する広告の表示はサイト側が決めるため、毎回広告が出る保証はありません。
これはGoogle広告等の配信サービスとの直接連携ではありません。

### お金とプレイヤー取引

ポーズ画面の **Sum1re 財布 / 取引** を開くと、Sum1reコ↑イン↓の残高、入出金、近隣プレイヤーとの取引を操作できます。コインの右クリックでも手持ち分を入金できます。1コインとSum1re札↑たば↓（10コイン分）があり、村人・行商人のエメラルド交易はSum1re札↑たば↓（10コイン分）で支払います（エメラルド1個＝10コイン）。

敵の討伐・鉱石・スポーンブロック破壊で残高が増えます。初期値は10/2/100コイン。設置した鉱石・シルクタッチ回収は報酬対象外です。

プレイヤー取引は相手が依頼を承諾してから開始。自分の持ち物をクリックして提示し、提示をクリックして解除します。コインの金額を提示して、双方が内容を承諾すると成立します。提示変更は承諾を解除します。コインだけの送金や物々交換も可能。閉じる・切断・距離超過・時間切れならキャンセルされます。

設定は「通貨・財布」「報酬」「村人交易」「プレイヤー取引」から変更できます。ショップは今後の拡張予定です。ワールドをバックアップする際は、通常のplayerdataとdata/sum1rem0d-state.jsonを同じ時点で保存してください。

### JSON5の設定ファイル

サーバー設定は`config/sum1rem0d.json5`、個人設定は`config/sum1rem0d-client.json5`へ保存します。初回は同名の旧`.json`から値を自動移行し、旧ファイルを変更せず残します。両方ある場合は`.json5`を使用します。破損ファイルから初期値への置き換えは行いません。

```json5
{
  features: {
    coin_rewards: {
      // 討伐の報酬。自分のメモも保存できます。
      kill_coins: 10,
    },
    vegan: {
      forbidden_items: [
        'minecraft:beef',
        'minecraft:porkchop',
      ],
    },
    ore_drops: {
      mapping: {
        'minecraft:coal_ore': 'minecraft:redstone',
      },
    },
  },
}
```

説明・初期値・範囲・設定範囲・適用タイミングをコメントとして生成します。`[Sum1reM0d]`から`[/Sum1reM0d]`の範囲は自動更新される説明です。手書きメモはこの範囲の外へ追加してください。保存時は2スペースの整形と`//`コメントへ統一するため、元の空白・引用符・コメント位置は変わることがあります。削除された項目のメモは末尾へ退避します。

ファイルを直接編集した値は再起動で読み込みます。ゲーム内Configの「適用」は従来どおり反映します。JSON5対応は`marhali/json5-java 3.0.0`（Apache-2.0）を使用。ライブラリは同梱し、Mod本体のライセンスはBlueOak-1.0.0を維持します。第三者ライセンスは[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。

### XP銀行・設備のコイン払い

財布画面の **XP銀行** から、XPポイントと残高を交換できます。初期値は **1 XPポイント＝1コイン**、双方向・手数料なしです。レベルではなく現在のXPバーのポイント数で計算します。

金床とエンチャントは **消費レベル1＝10コイン**。エンチャントの3段目（必要レベル30）は残高300コインが必要で、実際の支払いは30コインです。XPは減らず、ラピスラズリ・金床の修理素材は従来どおり必要です。金床の「コストが高すぎます」制限も残ります。

Config画面の `coin_anvil` / `coin_enchanting` / `xp_bank` で個別に無効化、料金・交換単位・交換方向・手数料・上限を調整できます。変更は次の操作から適用され、設備のコイン払いを無効にすると通常のXP払いに戻ります。

### チャット報告防止（No Chat Reportsの主要機能）

サーバー設定の `no_chat_reports.enabled` がONなら、プレイヤーチャットを署名のないシステムメッセージへ変換し、`enforce-secure-profile` の要求を解除します。既定はON。通常の名前・装飾と内容フィルターを維持し、署名確認待ちが増え続けないように配信します。NCRのサーバー検出にも対応します。

個人設定の `no_chat_reports.suppress_signing` は自分の署名送信を抑制します（既定ON、再接続から適用）。サーバー設定とは独立しており、署名必須の外部サーバーではOFFにして再接続してください。サーバー側の機能切替後も再接続してください。OFFで通常の配信・署名条件に戻ります。

暗号化チャットやNCR独自の画面は含みません。既存の署名付きチャットを消す機能ではなく、システムチャット化により個人ブロックやチャット専用Modの動作が変わる場合があります。[参照元](https://github.com/Aizistral-Studios/No-Chat-Reports)はWTFPLで公開されており、出典とライセンスを同梱しています。

### 検索候補

Wiki・Configの検索欄に入力すると最大5件の候補が表示されます。機能名・内部IDに対応し、Wikiでは説明文（例: 石鹸）からも候補を探します。完全一致・先頭一致を優先し、英字の大文字小文字・全角英数を区別しません。

候補をクリック、または↑↓で選んでEnterを押すと、記事・設定を直接開きます。TabはIDの補完、Escは候補だけを閉じます。候補未選択のEnterと検索ボタンは通常検索です。個人Configでは個人設定に含まれる機能だけが候補になります。

個人設定の「ゲーム内Wiki」→「Wiki・Configの検索候補を表示」でON/OFFを切り替えられます。保存後すぐに反映されます。

### HUDのカスタマイズ・画面ショートカット

個人設定の「清潔度」「Sum1reコ↑イン↓」で、それぞれのHUD表示・基準の四隅（0左上/1右上/2左下/3右下）・端からの横/縦距離・倍率・背景不透明度・文字色（#RRGGBB）・影・表示名を変更できます。表示名が空欄なら数値のみ。清潔度はバー表示・通常色・半分未満の色も調整できます。保存後即時反映し、ウィンドウサイズやGUI倍率に応じて画面内へ補正します。F1でも隠れます。

Minecraftの **設定→操作設定→キー設定→Sum1reM0d** に、Wiki・Config・財布/取引を開く3項目を追加しています。初期値は未割り当て。割り当てはバニラのoptions.txtに保存されます。ゲーム内でほかの画面を開いていない時に使え、入力中の画面には割り込みません。Wiki/通貨を無効にした場合はその画面をキーから開けません。サーバーConfigの変更権限は従来どおりです。

インベントリ交換は朝の排他的な異変抽選で選ばれた日に1回、初期値では同一ディメンション内の生存サバイバル/アドベンチャーをランダムなペアにして上から2段目9枠を交換します。奇数人の余りは対象外。防具・オフハンド・残高は対象外で、物理コインは対象枠内なら交換。結果はそのまま残り、満月条件・承諾操作はありません。

### クリエイティブでのコイン入出金・取引依頼通知

コインの入手元は記録していません。クリエで出したコインでもサバイバルでは入金できます。クリエ中の入出金は初期設定で禁止しており、サーバー設定の通貨項目 `allow_creative_wallet` をONにすると入金・出金・右クリック入金を許可します。XP銀行とプレイヤー取引のクリエ制限は維持します。財布では利用できないボタンを無効にし、クリエ制限などの理由を表示します。

新しい取引依頼は送信者名付きのトーストで画面右上へ通知します。財布/取引画面で承諾・拒否できます。個人設定の「双方承諾のプレイヤー取引」→ `toast_enabled` / `toast_seconds` でON/OFFと表示秒数（初期5秒）を変更できます。表示時間にはMinecraft標準の通知時間倍率も適用します。同じ依頼の定期同期では繰り返さず、依頼の終了や切断で閉じます。通知がOFFの間に届いた依頼は、ONへ戻しても遡って通知しません。

### 16×16テクスチャと泥だんご

コイン・Sum1re札↑たば↓・石鹸・泥だんご・Modアイコンを新規生成し、独自ゲーム用PNGをすべて16×16に統一しました。札束は緑の紙幣束として描き直し、従来のcoin_roll IDと10コインの価値を維持しています。[画像一覧](art/preview/redesign-16x16.png)・[生成プロンプト](art/prompts-16x16.json)・[書き出し手順](art/README.md)。

**泥だんご** は右クリックで自分の清潔度を下げる、石鹸の逆のアイテムです。初期値は1個で25低下、待ち時間20tick。土＋粘土玉から4個クラフトできます。清潔度0や効果量0では消費せず、クリエイティブでは通常どおり消費しません。サーバーConfigの `mud_ball` でON/OFF・低下量・消費・待ち時間・レシピの材料/出力を設定できます。清潔度機能がOFFなら使用・クラフトを停止します。水や石鹸で清潔度を戻せます。


## ネザーの異変と追加ルール

朝の排他的な抽選に、ナイリウム横倒し・旧ネザーラックを追加しました。
アーダイト／マニュリン化はConfigで常時ON/OFFを切り替えます。
名前・モデル・色調だけが変わり、ID・性能・ドロップは変わりません。テクスチャの開始と解除時はリソースを再読み込みします。
アーダイト／マニュリンは専用PNGへ切り替え、装備中の防具にも反映します。ツール・防具はバニラの画素配置と模様を保った素材色のバリエーションです。

以下の通常機能も、それぞれサーバーConfigからON／OFFできます。

- 遮光ガラスをすり抜ける（遮光性・選択判定を維持）。
- ピグリンの取引通貨を鉄インゴットに変更。金装備の敵対回避と取引結果は通常どおり。
- クラフト材料の紙と革を交換。除外レシピIDを指定でき、設定変更時にレシピブックとクラフト結果を更新。
- ネザー金鉱石の金塊を同数の金ブロックに変更。幸運・シルクタッチは通常の抽選を利用。
- ネザーラックはハサミで高速採掘。他の道具は遅くなり、速度を調整可能。
- 虫特効がプレイヤーとエンドラにも追加ダメージ（初期値2.5×レベル）。対象と量を調整可能。
- 自然スポーン・チャンク生成のモブが30％で上下反転。名前を上書きせず、保存・同期して再抽選を防止。
- 農民の就職・補充用ブロックを土の道に変更。
- オーク・ダークオークの葉から0.001％でエンチャ金リンゴを追加ドロップ。ハサミとシルクタッチを除外。


## 剣ガードと混色コンクリート

ダメージ軽減を武器に付与できます。初期値では1レベルにつき与ダメージが10％減り、剣は右クリックで前方の通常攻撃や矢を15％×レベル軽減します。構え始め5tickは防げず、ガード時に耐久を消費。盾・食べ物など使用可能なオフハンドを優先します。背後、貫通矢、火・落下・毒などは防げません。設定で対象武器/ダメージ・軽減率・攻撃力低下・待ち時間・方向・耐久消費を調整できます。

コンクリート1個＋染料1～8枠で、革防具と同じ方式の自由な混色ができます。同じ染料を複数枠へ置いて比率を変えられ、作った混色コンクリートも再染色可能。色は配置・回収・保存・同期で維持されます。建築タブに16色の初期バリエーションを追加しました。粉末は対象外で、専用BlockEntityで色を保存するためピストン移動はできません。ConfigをOFFにしても既存の色や回収は維持します。

## 追加の配線・装備・本

グロウストーンダストを地面へ設置すると、赤石に直接接続しない別配線になります。強度0～15が光量となり、赤石反転との逆状態で動作します。Configで反転連動を外し、通常／反転を固定することもできます。
ピストンの材料の下2列で根本だけを作れます。設置時、正面1ブロックをドロップなしで消します。岩盤も対象ですが、コンテナやポータルは初期設定で保護します。
普通の本と羽根ペンには編集画面で文字が勝手に追記されます。本と羽根ペン＋砂糖で作る「調教済みの本と羽根ペン」は通常どおり編集できます。
エメラルド・レッドストーン・ラピスそれぞれに道具5種と防具4種を追加します。採掘レベルは石相当。赤石装備は暗所でも装備自体を明るく描きます。性能変更は再起動後、レシピと発光の切替は次の処理から反映します。参加時にサーバーの登録済み性能を同期し、クライアント側の設定が異なる場合も採掘予測と装備表示を揃えます。

## 自由色の羊毛とベッド

羊毛と染料をクラフトすると、革防具と同じ計算で24bitの色を混ぜられます。混色羊毛3個＋木材3個で同じ色のベッドを作れ、異なる羊毛3個ならその色を混ぜます。ベッドへの直接染色も可能です。
色はアイテム・設置・破壊・保存・通信で保持します。ベッドは睡眠と村人の寝床に使えます。これらはブロックエンティティを使うため、バニラのピストンでは移動できません。

## Sumzon・サブスクリプション

財布のSumzonボタン、またはバニラのキー設定で割り当てた専用キーから開きます。登録済みアイテムを検索・分類してカートへ追加し、Sum1reコインで購入できます。初期設定では技術用アイテムなどを除外し、価格と除外品をConfigで変更できます。商品は各アイテムの標準状態で販売し、任意のNBT付き品は扱いません。
注文時に商品代＋送料を支払い、配達後に受取ボックスで空き枠分を受け取ります。残りは保管され、注文履歴は64件ずつ表示します。Sumzon Primeは送料無料・配達短縮です。広告プレミアムはModが開く広告を停止します。YouTube等のサイト自身の広告は対象外です。
契約期間と配送時間は保存されるサーバー経過tickで計算し、睡眠や時刻変更では進みません。自動更新は初期OFFで、明示的にONにした場合だけオンライン中に更新します。残高不足・料金や期間の変更時には停止します。購入機能をOFFにしても、支払済みの契約期間や商品の受取権は維持します。

## 専用テクスチャ

装備はバニラの輪郭・模様・陰影の位置を保ち、エメラルドは緑、赤石は赤、ラピスは青、マニュリンは紫にしています。木の柄は元の色を維持します。アイコンは拡大縮小せず16×16の専用PNGへ書き出し、着用画像はバニラのUVサイズを維持しています。
調教済みの本は紫の表紙と羽根ペン、留め具の専用画像です。インゴット・混色素材・配線・ピストン根本も専用画像を使用します。制作記録と配色案・書き出し手順は[art](art/README.md)にあります。
